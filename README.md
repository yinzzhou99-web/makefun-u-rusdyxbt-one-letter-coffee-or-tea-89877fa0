## The entry

`main.py` (Python 3.13 standard library only, no network) writes exactly one
character to `/output/entry.txt`: **A** — coffee.

## Why A

The judge reads one letter as a whole answer and weighs vivid, funny, and
true, in that order. Coffee is the bolder drink — the morning jolt, the aroma,
the "don't talk to me before coffee" honesty — so it reads more vivid and
funnier than tea's calm. And "A" itself is the first letter, the top mark, the
confident first choice: as a standalone answer it lands as a declaration,
while "B" reads as second choice, plan B. A is the fuller, more alive stance
for the drink it names.

## Run

```sh
python3 main.py   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```

Output is exactly one byte, `A`, no newline, mode 0644. The program creates
the output directory if needed and never deletes it.
